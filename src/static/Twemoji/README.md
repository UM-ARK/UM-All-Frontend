Twemoji 圖像由 Twitter, Inc. 及其他貢獻者提供，採用 [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/) 授權。完整授權條款見同目錄的 `LICENSE-GRAPHICS`，原始專案見 [jdecked/twemoji](https://github.com/jdecked/twemoji)。
